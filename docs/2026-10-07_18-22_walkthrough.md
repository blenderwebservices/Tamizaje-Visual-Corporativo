## 1. Causa del Error HTTP 400 al Hacer Push
El error `HTTP 400 (Bad Request)` ocurría debido a que la configuración predeterminada del búfer de transferencia HTTP de Git (`http.postBuffer`) era insuficiente (por defecto ~1 MB) para subir el commit inicial en una sola petición. Dado que el repositorio incluye archivos binarios pesados (como el diagrama de flujo `docs/Flujo_de_SpotVision_Visual_Corporativo.png` de 5.2 MB y el PDF de muestra), Git intentaba fragmentar el payload (*chunked transfer*), el cual fue rechazado por el proxy de GitHub.

---

## 2. Solución Aplicada
1. Se amplió el búfer de subida HTTP de Git a 500 MB:
   ```bash
   git config http.postBuffer 524288000
   ```
2. Se publicó la rama `main` y se configuró el rastreo remoto con éxito:
   ```bash
   git push -u origin main --verbose
   ```
3. El paquete completo de **6.07 MiB** (181 objetos) fue recibido, desempaquetado y registrado en GitHub.
